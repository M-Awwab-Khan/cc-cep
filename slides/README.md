# Presentation slides

Standalone HTML deck for the CEP viva. No build step: open `index.html` in a browser (Chrome or Edge recommended).

- **Next / back:** → ↓ Space Enter / ← ↑ Backspace. Some slides reveal items one click at a time.
- **N** toggles speaker notes. **F** toggles fullscreen. **Home / End** jump to first / last slide.
- Slide 16 and slide 22 have clickable condition tabs.
- Fonts load from Google Fonts; offline, the deck falls back to system fonts.

Numbers come from `results/curated/final-study-summary.json` (main study) and `results/curated/followup-table.tex` (paced follow-up). The paced follow-up is a separate, time-separated evaluation and is never pooled with the main study.
